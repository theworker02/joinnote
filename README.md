# joinnote

Join CSV/TSV note tables for quick inspection and cleanup.

**Site:** https://theworker02.github.io/joinnote/

## Install / run

```bash
git clone https://github.com/theworker02/joinnote.git
cd joinnote
node src/cli.js
node --test
```
